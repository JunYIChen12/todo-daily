# Packaging
No-Python: `powershell -NoProfile -ExecutionPolicy Bypass -File .\make-exe-package.ps1` -> `artifacts\packages\todo-daily-windows-exe.zip`. Python: `powershell -NoProfile -ExecutionPolicy Bypass -File .\make-package.ps1` -> `artifacts\packages\todo-daily-windows-python.zip`. Install via `install.ps1`/`install.bat`; copies to `%LOCALAPPDATA%\TodoDaily`, creates `todo-data\`, registers startup task, starts unless `-NoStart`, opens localhost.
